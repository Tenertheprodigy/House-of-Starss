# House of Stars

A responsive Next.js / TypeScript site with Tailwind CSS, Framer Motion, and custom animated SVG liquidity diagrams.

## Run locally

```sh
npm install
npm run dev
```

Open http://localhost:3000.

## Verify and build

```sh
npm run typecheck
npm run build
npm start
```

All exchange CTAs use https://t.me/houseofstarsorderbot. The Telegram conversation is an illustrative preview; its payout buttons update only local preview state. Asset support and settlement depend on the order. Legal documents are explicitly marked as placeholders and must be supplied before publication.

The page includes keyboard-accessible navigation, native FAQ disclosures, responsive layouts, SEO metadata, and reduced-motion styles.
